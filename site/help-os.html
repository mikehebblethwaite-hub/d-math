Boot Delta Hex OS

Try it in a virtual machine first. With QEMU and the OVMF firmware installed:

  1. Make a folder for its drive: mkdir -p esp/EFI/BOOT
  2. Put BOOTX64.EFI in esp/EFI/BOOT/
  3. Start it: qemu-system-x86_64 -bios /usr/share/ovmf/OVMF.fd -drive format=raw,file=fat:rw:esp -m 1024 -net none -device qemu-xhci -device usb-tablet
  4. The desktop is seven hex tiles. Arrows or Tab move, Enter or a click opens a tile, Esc comes back.
  5. Dragonfly, the engineer’s assistant: type two of volts, amps, ohms and watts, like C v 4 ohm 6 s, then Enter.
  6. Say: a D numeral, or a sum like 7 + 6, then Enter.
  7. Terminal (the t key): help lists the commands. Put lab.efi next to the EFI folder and run lab.efi opens the lab room.
  8. Switch it off with the Off tile, or Esc on the desktop. If the window keeps hold of your mouse, Ctrl+Alt+G lets it go.

To build it yourself from the source: lang/delta efi os/start.delta -o esp/EFI/BOOT/BOOTX64.EFI. Delta Hex OS is early: it reads the machine’s memory map and draws on the screen, and it does not write to any drive.
