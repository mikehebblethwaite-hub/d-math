Boot Delta Hex OS

Try it in a virtual machine first. With QEMU and the OVMF firmware installed:

  1. Make a folder for its drive: mkdir -p esp/EFI/BOOT
  2. Put BOOTX64.EFI in esp/EFI/BOOT/
  3. Start it: qemu-system-x86_64 -bios /usr/share/ovmf/OVMF.fd -drive format=raw,file=fat:rw:esp -m 1024 -net none -device qemu-xhci -device usb-tablet
  4. Sign in: the first time, make the first account: a name (a–z, 1–9 and -), a password twice (8 letters or more), and your unlint pod (it fills in https://NAME.pods.unlint.com/). The machine never keeps the password, only a check worked out from it (PBKDF2-SHA-256, 100,000 rounds). A wrong password makes the next try wait, longer each time. Your files live in your own folder, users\NAME, and each save waits on your outbox to sync to your pod.
  5. The desktop is seven hex tiles. Arrows or Tab move, Enter or a click opens a tile, Esc comes back.
  6. Dragonfly, the engineer’s assistant: type two of volts, amps, ohms and watts, like C v 4 ohm 6 s, then Enter.
  7. Say: a D numeral, or a sum like 7 + 6, then Enter.
  8. Terminal (the t key): help lists the commands; whoami, pod, signout, and account NAME PASSWORD for one more person. Put lab.efi next to the EFI folder and run lab.efi opens the lab room.
  9. Switch it off with the Off tile, or Esc on the desktop. If the window keeps hold of your mouse, Ctrl+Alt+G lets it go.

To build it yourself from the source: lang/delta efi os/start.delta -o esp/EFI/BOOT/BOOTX64.EFI. Delta Hex OS is early. It keeps accounts and each person’s files on its boot drive; the files are not sealed yet (anyone holding the drive can read them: sealing them with each person’s key comes next), and the outbox waits for the machine’s own link to the web before it reaches the pod.
