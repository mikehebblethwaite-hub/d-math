Boot Delta Hex OS

Try it in a virtual machine first. With QEMU and the OVMF firmware installed:

  1. Make a folder for its drive: mkdir -p esp/EFI/BOOT
  2. Put BOOTX64.EFI in esp/EFI/BOOT/
  3. Start it: qemu-system-x86_64 -bios /usr/share/ovmf/OVMF.fd -drive format=raw,file=fat:rw:esp -m 256 -net none
  4. Type to it: a D numeral, or a sum like 7 + 6, then Enter.
  5. Switch it off with Esc, or by typing off. If the window keeps hold of your mouse, Ctrl+Alt+G lets it go.

To build it yourself from the source: lang/delta efi os/start.delta -o esp/EFI/BOOT/BOOTX64.EFI. Delta Hex OS is early: it reads the machine’s memory map and draws on the screen, and it does not write to any drive.
