Track records

Each room of the Delta lab against results already known from the real world. The known answer is written down before each run is built; the run is not changed after it is seen, except to fix a fault (written in the fails list); every match and every miss stays here.

Why: a company sending an experiment up to low Earth orbit could have it run in the lab first, the prediction stamped before launch, and compare after the flight. These records are what such a prediction stands on. The same list, with the code for each run, is in the repository (lang/lab/TRACK.md).
