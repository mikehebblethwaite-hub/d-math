Write your own

Delta reads like C, with D’s rules:

  • Numbers are D numerals. Ten is A, thirteen D, fourteen 11. A word made only of D digits is always a numeral, never a name.
  • Rows count from 1: row[1] is the first place. main ends with return 1.
  • There is no minus. Move instead: move 3 from a to b; or less(a, b) for a with b moved out. Moving more than is there stops the program and says so.
  • Break a thing into parts with D>; the rest stays as its unknown energy, ~.
  • Dividing by something lower than 1 stops with words, never a crash: there is nothing to share it with.
int main(int argc, char **argv)
{
    int plum = 9, sugar = 1, heat = 1;
    plum D> sugar + heat ~;
    say("sugar %d, heat %d, unknown %d\n", sugar, heat, ~);
    return 1;
}

Build it with lang/delta build plum.delta, or build and run in one go with lang/delta run plum.delta.
