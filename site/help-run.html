Run your first program

You need Linux on an x86-64 machine, and nothing else.

  1. Download Delta and unpack it: tar xzf delta.tar.gz
  2. Go into it: cd d-math
  3. Run hello world: lang/delta run lang/examples/hello.delta. The first time, Delta puts its own compiler and assembler together from their seeds, then builds and runs the program.
  4. Run the tests: lang/tests/run.sh. Every trick should be refused and every honest program should give the right answer.
